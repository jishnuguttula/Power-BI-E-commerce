# E-Commerce Sales Dashboard | Power BI

## Project Overview

This project presents an **interactive E-Commerce Sales Dashboard** built using **Power BI** and a structured **SQL-based dataset**.
The dashboard provides insights into sales performance, customer behavior, and product trends for the year **2025**.

The goal of this project is to demonstrate skills in **data analysis, data visualization, and business intelligence reporting**.

---

## Key Metrics

The dashboard tracks the following key performance indicators (KPIs):

* **Total Revenue**
* **Total Orders**
* **Total Customers**
* **Total Quantity Sold**

These KPIs help quickly understand the overall performance of the e-commerce business.

---

## Dashboard Features

### 1. Sales Performance Analysis

* Monthly revenue trend visualization
* Identification of revenue fluctuations across the year

### 2. Product Insights

* Top 10 best-selling products
* Sales performance by product category

### 3. Customer Insights

* Top 10 customers based on revenue and order count
* Customer purchase behavior analysis

### 4. Geographic Insights

* Orders distribution by city

### 5. Interactive Filters

Users can dynamically filter the dashboard by:

* City
* Product Category
* Order Date

This allows interactive exploration of sales data.
